# Rachayati Designs 🪷

> **Spiritual Products for a Soulful Life**  
> Inspired by Tradition. Designed for Devotion.

Welcome to the official repository for **Rachayati Designs**, an artisanal spiritual products and devotional decor brand.

---

## 🌟 Key Features

- **Devotional Catalog**: Browse Tulsi Maharani dresses, LED lit Mahamantras, sacred wall hangings, car dashboard keepsakes, and car hanging accessories.
- **Dedicated Collections**: Rich showcase of distinct sacred categories.
- **WhatsApp Direct Inquiries**: Instant order assistance and customer support directly linked via WhatsApp.
- **Responsive Mobile Experience**: Tailored mobile design with 2-column collection layout, touch-friendly interactions, and smooth animations.
- **Lightweight & Fast**: Pure HTML5, CSS3, and modern Vanilla JavaScript with zero heavy framework overhead.

## 🚀 Running Locally

To preview the website locally on your computer:

```bash
# Using Python
python -m http.server 3000

# Or using Node.js serve
npx serve .
```

Then visit `http://localhost:3000` in your web browser.
